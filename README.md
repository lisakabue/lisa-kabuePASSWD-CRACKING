# Password Cracking Using John the Ripper (Johnny)

## Project Overview
This project involved practical password-cracking exercises using John the Ripper (Johnny), a password security auditing and recovery tool.

## Objectives
- Understand how password-cracking tools work.
- Practise password recovery on protected files.
- Explore password security and the importance of strong passwords.

## Tools Used
- John the Ripper
- Johnny (Graphical User Interface)

## Practical Activities
- Performed password-cracking exercises on two locked Pdf files.
- Successfully recovered the passwords.
- Captured two flags provided by Networkwalks Academy as proof of successful completion.

## Learning Outcomes
- Gained hands-on experience using John the Ripper.
- Improved understanding of password security and recovery.
- Gained practical exposure to password-cracking techniques in a controlled learning environment.

## Conclusion
Successfully completed two password-cracking challenges and captured both flags. This exercise strengthened my practical cybersecurity skills and understanding of password security.
